# Компьютерная графика — лабораторная работа №2

**Тема:** Камера и освещение. Объект варианта — правильный додекаэдр из лабораторной работы №1.

Приложение использует C++20, Vulkan, GLFW и ImGui. Исходный стартовый проект: [vulkan-starter-app](https://github.com/vladeemerr/vulkan-starter-app).

## Реализовано

- Управление камерой: позиция, направление (yaw/pitch), угол обзора и переключение перспективной/ортографической проекции.
- Процедурно рассчитанные нормали граней и освещение по модели Блинна–Фонга во фрагментном шейдере.
- Настройки направленного света, ambient-составляющей и материала модели (альбедо, цвет блика, коэффициент блеска).
- Динамические массивы точечных и прожекторных источников в Vulkan storage buffers. Их можно добавлять, удалять и редактировать в интерфейсе.
- Обратноквадратичное затухание для точечных и прожекторных источников; для прожекторов настраиваются направление, внутренний и внешний углы с мягкой границей.
- Отдельные наборы дескрипторов сцены и модели: сцена хранит камеру и источники света, модель — трансформацию и материал.
- Сохранены несколько объектов и анимация додекаэдра из предыдущей лабораторной.

## Сборка

Нужны компилятор C++20, Vulkan SDK, CMake и `glslc` из Vulkan SDK в `PATH`.

```bash
cmake --preset msvc-debug
cmake --build build-debug --parallel
```

Запускайте приложение из корня проекта, чтобы относительные пути к скомпилированным шейдерам разрешались корректно.

## Управление

В панели ImGui доступны параметры камеры, проекции, направленного и ambient-света, материалов объектов, а также добавление и удаление точечных и прожекторных источников с настройкой их параметров.
